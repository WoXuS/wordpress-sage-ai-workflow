# Pull requests — archiwum opisów

Repozytorium powstało jako scrubbowana kopia prywatnego repo klienckiego, więc
same PR-y (metadane GitHuba) nie przeniosły się razem z historią gita. Ich opisy
przeniosły się tutaj, bo to w nich jest zapisany proces: **co** zmieniał dany PR,
**dlaczego** tak, i **jak** zweryfikowałem wynik przed mergem.

Merge commity w historii (`Merge pull request #N from …`) nadal wskazują na te
numery, więc `git log --graph` odtwarza całą topologię gałęzi.
