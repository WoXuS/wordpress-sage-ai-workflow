# Homepage (front-page) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the PL homepage (`front-page.blade.php`) 1:1 with Figma — 7 sections — replacing the temporary design-system showcase.

**Architecture:** Thin `front-page.blade.php` includes 7 section partials (`partials/home/*`). Static copy + blog data come from a `Home` view composer (PHP arrays now, `get_field` later). Three small components (`<x-hexagon>`, `<x-service-tile>`, `<x-post-card>`). Single-source responsive (render once, switch by breakpoint).

**Tech Stack:** Sage 11 / Acorn (Blade), Tailwind v4 CSS-first + `fluid-tailwindcss` (`fl-*`), Blade Icons (`<x-icon-*>`/`@svg`), Vite. Local: docker-compose (`http://localhost:8080`), `make up`/`yarn build`/`make dev`.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-07-10-homepage-design.md`. Figma file `2QUIxJAqMGrvChL7X4aIdr`, desktop node `2:2396`, mobile node `395:2110`.
- **No hardcoded heights** — height from padding + content; fluid spacing via `fl-*`; raw `clamp()` only where needed, kept round.
- **Single-source responsive** — one markup, mobile-first, override at `lg:`. No duplicate DOM per breakpoint.
- **Static content lives in the `Home` composer**, annotated `// TODO: get_field(...) in ACF phase`. Only the blog is dynamic (real WP data).
- **Legacy URLs**: services under `/uslugi/<slug>`, DBiP under `/dbip-chapters/`. Built with `home_url(...)`, single-sourced in the composer.
- **Palette/tokens**: `bg-red`/`text-red`/`text-white`/`bg-cream`, fluid `--text-*`, `<x-container>` = `.o-wrap` (max 1440, fluid gutter). Icons `currentColor`.
- **Verification** (no unit suite): `yarn build` clean + `curl` DOM/grep + visual compare vs Figma at ~375px and ~1440px. Clear Blade cache when a view doesn't refresh: `make wp ARGS="acorn view:clear"`.
- **Copy**: use the Polish text captured in this plan; verify verbatim against Figma text nodes with `get_design_context` on the section node during the task.

@layer components {
  .c-hex {
    aspect-ratio: 1 / 1.1547;            /* pointy-top regular hexagon */
    clip-path: polygon(50% 0, 100% 25%, 100% 75%, 50% 100%, 0 75%, 0 25%);
    display: grid;
    place-items: center;
  }
  .c-hex--solid { background-color: var(--color-red); color: var(--color-white); }
  .c-hex--outline {
    background-color: var(--color-red);   /* border effect via padded inner mask */
    clip-path: polygon(50% 0, 100% 25%, 100% 75%, 50% 100%, 0 75%, 0 25%);
  }
  .c-hex--outline .c-hex__inner {
    background-color: var(--color-white);
    width: calc(100% - 4px);
    height: calc(100% - 4px);
    clip-path: polygon(50% 0, 100% 25%, 100% 75%, 50% 100%, 0 75%, 0 25%);

  .c-hex__inner {
    padding: 12%;
