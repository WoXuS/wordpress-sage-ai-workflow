## What

Makes the entire homepage content-managed via ACF (all sections editable in wp-admin) and adds a proper **English** homepage.

Follows the established `fromAcf() ?? fromHardcoded()` pattern (as in `Usluga`/`Dbip`). Fields use **ACF Pro** (groups, repeaters, icon/link/image pickers) per the project's direction — when Pro isn't active, free ACF ignores them and the composer falls back to hardcoded content, so nothing breaks.

## Changes

- **`group_home.json`** — front-page field group (`Page Type = Front Page`): hero, about, memberships, why (`hexes` repeater), services (`items` repeater w/ icon + link), dbip (paragraphs + CTA), blog texts.
- **`HomeServiceProvider`** — `acf/location/match_rule` filter so the "Front Page" rule also matches the **Polylang translation** of the front page. The EN home (a linked translation) gets the fields with **no hardcoded post IDs** in the versioned JSON.
- **`Home` composer** — reads the current-language front page; ACF images resolve to a URL with theme-asset fallback; the hardcoded fallback now **branches PL/EN** so the English home renders in English immediately.
- **Home partials** — take resolved image URLs; `services` uses the new `{heading, items}` shape.
- **`docs/design-system.md`** — updated §4/§9/§10/§13/§16.
