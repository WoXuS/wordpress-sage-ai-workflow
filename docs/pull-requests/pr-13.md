## What

Two header-nav interactions requested for the MVP.

### 1. Active state + hover on menu items
- **Active state** — the current page's menu item now shows a persistent underline (WP `current-menu-item`/`-ancestor`/`current_page_*`). New `components/nav.css`. Scoped `> a:not([href*="#"])` because WP falsely flags the in-page section anchors (`O nas`, `Usługi`, `Kontakt` → `/#…`) as *current* on the home page they point to — the `:not` excludes them so only real page items (Blog, Kariera, INFLOW) light up.
- **Hover** — desktop nav had **no** working hover: a `lg:[&_a:hover]:text-red` utility was overriding the ghost button's own hover with the same red (a no-op). Removed it, so links now use the project's `c-btn--ghost` hover (red → red-dark), consistent with the buttons.

### 2. Contact link → footer scroll + nudge (no contact page in MVP)
- `app/filters.php`: any nav item pointing at `#footer` (the Contact/Kontakt item) is rewritten to a **pure** `#footer` hash + `data-contact-footer="true"`, so it same-page scrolls to the footer contact block on **every** URL (the existing `/#footer` full-reloaded to home on subpages).
- New `modules/contact-highlight.js`: ~550ms after the click (once `anchor-scroll` settles), toggles `.is-nudging` on the footer phone + email links (`data-contact-highlight` in `footer-office.blade.php`), clearing on `animationend` so it replays. `contact-nudge` scale/wiggle keyframes in `nav.css`; reduced-motion safe.
