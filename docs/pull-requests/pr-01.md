Design-system foundation for the ARPI theme — Figma tokens wired into Sage 11 / Tailwind v4, reusable components, and the icon system.

## What's in here

**Foundation (7 planned tasks):**
- **Design tokens** (`theme.css`, `@theme static`) — cleared Tailwind palette, brand-only `--color-red/black/white/cream`, fluid `--text-*` clamps (375→1280px), `--wrap-padding-inline`.
- **Fluid typography** — semantic `h1–h3`/`body`/`a` styled in `@layer base` (rem for font-size only, px elsewhere; anti-boilerplate: shared size tokens + contextual line-height/tracking).
- **Geomanist Regular** `@font-face`.
- **`.c-btn` / `<x-button>`** — solid/outline/ghost, no fixed dimensions (compose from padding + line-height), hover via `color-mix`.
- **`.o-wrap` / `<x-container>`** — max 1280px, fluid gutter, no vertical padding.
- **Icon system** — `blade-ui-kit/blade-icons` custom set (`resources/icons/`, prefix `icon`), `<x-icon-*>` inline SVG colorable via `currentColor`.
- Multi-file CSS (thin `app.css` index + partials, cascade layers), ITCSS-lite naming (`c-`/`o-`/`u-`).

**Icon library:** 37 icons exported from Figma, normalized — `fill/stroke: black → currentColor`, root `width`/`height` stripped (sizing via `.size-6`/viewBox), kebab-case names. White preserved as clipPath structure + deliberate separator strokes.

## Architecture notes / decisions
- `@theme static` is required: Tailwind v4 tree-shakes unreferenced `@theme` vars, which would drop tokens from `:root` and `theme.json`. Documented inline.
- Verification is build-artifact grep + rendered-DOM curl (no unit suite — this is a CSS/theme layer). All green; built CSS confirmed loading (HTTP 200).

## Deferred (needs page layouts)
- **Solid-button hover legibility:** white text on 30% red is ~1.4:1 on a white background. Kept Figma-faithful for now; decide once page layouts show what background the solid button sits on. Recorded as provisional in the spec.
